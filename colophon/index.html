How this site was written

An AI assistant drafted this site's text from my notes and my answers to its questions. I corrected the drafts and approved every page before it was published.

Why static Astro

Every page is rendered to HTML at build time and served as static files, so a visitor downloads no framework runtime to read it. Angular and Next.js suit applications with heavy client-side state or a server behind them; this site is mostly text with one small interactive demo, so their runtimes would add weight without adding anything a reader could use.

Measured results

Accessibility and performance are measured on every release build: every page is checked with axe against WCAG 2.2 AA in both themes at phone and desktop widths, and Lighthouse runs with its mobile settings. The results for the current release, with the date and the method, are in the quality report .

Privacy

This site sets no cookies and shows no consent banner. Its fonts and scripts are served from the site itself. It is hosted on GitHub Pages, so GitHub receives the request for every page and file, with your IP address and browser details, as any web host does.

GoatCounter counts page views and a few named events without cookies. It receives the page address, the referrer and a coarse description of your browser and screen, not your identity.

The contact form is handled by Web3Forms, which receives what you type into it and emails it to me. A booking goes through Cal.com, which receives the details you enter there. Opening the WhatsApp link hands the conversation to WhatsApp.

The robots.txt file asks AI training crawlers to stay away. It is a request, not enforcement: a crawler that ignores it can still read the pages.
