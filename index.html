  1. The browser sends the buyer's message to the agent.
  2. The agent calls the model provider to decide the next step.
  3. The agent retrieves documents for the question.
  4. A grader checks what came back; a rejected result rewrites the query and retrieves again.
  5. Accepted results return to the agent.
  6. Before a cart or purchase-request action the graph stops, and the checkpointer saves its state.
  7. The browser runs the action and posts the result, and the agent resumes.
